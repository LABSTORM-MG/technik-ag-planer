# Sicherheit

Die App wird von Minderjährigen genutzt. Sicherheitslücken bitte **nicht** als öffentliches Issue melden.

## Meldung

Nutze die private Meldefunktion von GitHub: Reiter **Security** → **Report a vulnerability** in diesem Repository.

Bitte beschreibe:

- betroffene Funktion bzw. URL und Version
- Schritte zum Nachvollziehen
- mögliche Auswirkungen

Du bekommst in der Regel innerhalb von 7 Tagen eine Rückmeldung. Bitte veröffentliche Details erst, nachdem die Lücke behoben ist.

## Unterstützte Versionen

Sicherheitsupdates gibt es nur für die jeweils neueste Version.
