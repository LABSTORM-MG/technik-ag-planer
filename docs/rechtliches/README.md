# Rechtliches

> **Vorlagen, keine Rechtsberatung.** Die Texte beschreiben, welche Daten die App tatsächlich verarbeitet, und geben eine Gliederung vor. Vor dem Start müssen sie vom Betreiber vervollständigt und – weil die App von Minderjährigen genutzt wird – mit Schulleitung und Datenschutzbeauftragter der Schule abgestimmt werden (Feature-Liste, Abschnitt 11). Dabei auch klären, ob für Schülerinnen und Schüler unter 16 eine Einwilligung der Eltern nötig ist.

| Vorlage | In der App |
| --- | --- |
| [impressum.md](impressum.md) | `/impressum/` |
| [datenschutz.md](datenschutz.md) | `/datenschutz/` |
| [nutzungsbedingungen.md](nutzungsbedingungen.md) | `/nutzungsbedingungen/` |

Eingetragen werden die fertigen Texte im **Django-Admin → Rechtstexte** (Absätze durch Leerzeilen trennen; Links und E-Mail-Adressen werden automatisch anklickbar). Die Seiten sind ohne Anmeldung erreichbar und in der Landingpage, an der Anmeldung, im Anfrage-Formular und unter „Über die App“ verlinkt. Solange nichts eingetragen ist, zeigen sie „Noch nicht hinterlegt“.

Platzhalter stehen in eckigen Klammern: `[…]`.
